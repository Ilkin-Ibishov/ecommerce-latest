# Knowledgebase

Cross-cutting operational knowledge: environment quirks, tooling gotchas, infrastructure state,
and process lessons that aren't tied to one phase. Phase-specific implementation history stays in
`docs/audits/` and `docs/design-notes/`; this folder is for things a new session needs regardless
of which phase it's working on.

Add a file here when you hit something that cost real time to figure out and will cost the next
session the same time if it isn't written down. Update a file in place rather than appending a new
dated entry — this is a reference, not a log.

## Index

- [local-dev-environment.md](local-dev-environment.md) — running the app locally on Windows: known
  install/build quirks and the fixes.
- [supabase-projects.md](supabase-projects.md) — which Supabase projects exist, what's actually in
  them, and which one (if any) is safe to use for what.
